# ASD Semester 2

Repository ini berisi kumpulan materi, latihan, dan implementasi program dari mata kuliah **Algoritma dan Struktur Data (ASD) Semester 2** menggunakan bahasa pemrograman **C**.

Fokus utama repository ini adalah implementasi berbagai konsep struktur data dan algoritma dasar yang dipelajari selama perkuliahan, mulai dari array, linked list, stack, queue, rekursi, sorting, searching, hingga tree.

---

## 📚 Materi yang Dipelajari

Beberapa materi yang terdapat dalam repository ini antara lain:

- Dasar-dasar Algoritma
- Array dan Pointer
- Function dan Rekursi
- Searching Algorithm
- Sorting Algorithm
- Stack
- Queue
- Linked List
- Operasi File
- Dynamic Memory Allocation (`malloc`, `calloc`, `free`)
- Studi Kasus dan Latihan Soal

---

## 🛠️ Bahasa dan Tools

Repository ini menggunakan:

- Bahasa C
- GCC Compiler
- Linux Environment / Terminal
- IDE (VS code, nvim, nano, dll)

Beberapa implementasi program yang tersedia:
